# Security Policy

## Supported Versions

| Version         | Supported          |
| --------------- | ------------------ |
| Default Branch  | :white_check_mark: |
| Latest Release  | :white_check_mark: |
| Older Releases  | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories by clicking the "Report a vulnerability" button on this repository.

**Do not open public issues for security reports.**

## Response Targets

- We will acknowledge receipt of your vulnerability report within 5 business days.
- We will provide a status update within 14 days.
- We practice coordinated disclosure.
- Note: We do not offer a bug bounty program.
